Proyectos

Qué construí

AWS Reference Stack — infraestructura como código

Una arquitectura AWS pequeña pero con la forma de un sistema en producción, descrita entera en Terraform: un servicio web en contenedores detrás de un balanceador y una tubería de trabajo asíncrono, conectadas con permisos de mínimo privilegio. Se despliega con terraform apply y nada más.

  • Terraform
  • AWS
  • ECS Fargate
  • SQS
  • Lambda
  • IAM
  • Red en dos zonas de disponibilidad, con las tareas de cómputo en subredes privadas y salida a internet por un único NAT gateway.
  • Cola de trabajos con cola de mensajes muertos tras tres fallos, para que un mensaje envenenado no bloquee el consumo.
  • Cada permiso de IAM acotado al recurso que lo necesita: ninguna política con comodín.
